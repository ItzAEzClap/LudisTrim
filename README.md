### Macros

* `<root>`
* `<base>`: Resolves to `<root>/<game>`
* `<game>`
* `<home>`
* `<xdgConfig>`
* `<xdgData>`
* `<storeUserId>`
* `<osUserName>`
* `<winLocalAppDataLow>`: `%LOCALAPPDATA%Low` (Default: `C:/Users/%USERNAME%/AppData/LocalLow`)
* `<winLocalAppData>`: `%LOCALAPPDATA%` (Default: `C:/Users/%USERNAME%/AppData/Local`)
* `<winAppData>`: `%APPDATA%` (Default: `C:/Users/%USERNAME%/AppData/Roaming`)
* `<winDocuments>`: `%USERPROFILE%/Documents` (Default: `C:/Users/%USERNAME%/Documents`)
* `<winPublic>`: `%PUBLIC%` (Default: `C:/Users/Public`)
* `<winProgramData>`: `%PROGRAMDATA%` (Default: `C:/ProgramData`)
* `<winDir>`: `%WINDIR%` (Default: `C:/Windows`)
* `<macAppSupport>`
* `<macPreferences>`
